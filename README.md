Автоматизация тестирования QA-Desk

Репозиторий содержит UI-автотесты для платформы [qa-desk.education-services.ru]. В рамках проекта автоматизированы основные пользовательские сценарии, включая регистрацию, авторизацию и процесс публикации объявлений.

В проекте используется стандартный стек автоматизации на языке Python:
Python 3.10+
PyTest — для организации тестов, параметризации и управления фикстурами.
Selenium WebDriver — для прямого взаимодействия с элементами интерфейса браузера.
Локаторы вынесены в отдельный файл конфигурации (locators.py) для упрощения поддержки проекта при изменении верстки.
Использование исключительно явных ожиданий (WebDriverWait и expected_conditions) для обеспечения стабильности UI-тестов в условиях асинхронного рендеринга (React/Vue).

Для запуска тестов локально выполните следующие шаги:

1. Клонируйте репозиторий к себе на компьютер:
    git clone <https://github.com/katerinsplace/Sprint_5>
    cd <SPRINT_5>

2. Создайте и активируйте виртуальное окружение (рекомендуется):
   # Создание
   python -m venv venv
   
   # Активация для Windows
   venv\Scripts\activate
   
   # Активация для macOS/Linux
   source venv/bin/activate

3. Установите необходимые зависимости:
   pip install pytest selenium

Запуск тестов

Все команды выполняются из корневой папки проекта в активированном виртуальном окружении.

Запуск всех тестов в проекте:

  pytest

Запуск тестов с подробным выводом названий (детальный режим):
  pytest -v

Запуск конкретного теста по его имени (например, создание объявления):
  pytest -k test_create_ad_by_authorized_user -v
